# Forex AI Intelligence Engine

AI-assisted forex research and risk-management engine combining fundamental, technical, and ML signals.

## Core capabilities
- Technical indicators and market structure
- Fundamental score inputs
- ML probability interface
- Ensemble signal scoring
- ATR-based Stop Loss (SL) and Take Profit (TP)
- Risk/reward validation
- Position sizing from account risk
- Long/short trade setup generation
- Deterministic tests

> Research/decision-support software. Signals are not financial advice and should be validated with live market data, broker constraints, spreads, and execution conditions.
